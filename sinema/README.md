# Perde Sinema Yönetim Sistemi

Tkinter ve nesne yönelimli Python ile hazırlanmış sinema salonu uygulamasıdır.

## Çalıştırma

```bash
python sinema.py
```

Uygulama açıldığında örnek filmler, salonlar, seanslar ve biletler hazır gelir.
Veriler aynı klasördeki dört JSON dosyasına kaydedilir.

## Özellikler

- Film ve seans ekleme
- Seansa göre salon koltuk matrisini görme
- Boş koltuğa tıklayarak bilet satışı
- Dolu koltuk kontrolü
- Satış kaydını iptal etme ve koltuğu boşaltma
- Toplam bilet ve hasılat raporu
